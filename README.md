# Finance Data Analysis – Week 1

## 1. Project Overview
This project involves analyzing an investment dataset to understand respondents' investment preferences, participation in different investment avenues, and general investment behaviour.

The project is part of a weekly data analytics internship task focused on using data analysis tools to extract meaningful insights from raw data.

## 2. Business Problem
Understanding investors' preferences can help businesses and financial institutions identify popular investment options, understand customer behaviour, and make better-informed decisions.

This analysis aims to explore the available data and identify patterns that may support investment-related decision-making.

## 3. Dataset Description
The dataset contains information about respondents and their investment-related activities and preferences. Some fields represent investment avenues, such as mutual funds and equity markets, while Yes/No responses indicate participation or usage where applicable.

**Note:** The dataset was provided without a detailed data dictionary. Therefore, column meanings and assumptions are interpreted based on the available field names and values.

## 4. Tools Used
- Microsoft Excel 
- PivotTables
- Excel formulas
- Charts and visualizations, where applicable

## 5. Project Workflow
The analysis follows these steps:

1. **Data Inspection:** Examine the dataset structure, column names, data types, and available values.
2. **Data Cleaning:** Identify and address data quality issues where necessary.
3. **Data Analysis:** Use Excel formulas and PivotTables to summarize the data and examine investment preferences.
4. **KPI Development:** Create key performance indicators to communicate important findings.
5. **Visualization:** Present relevant findings using charts or dashboard elements, where applicable.
6. **Documentation:** Record the analysis process, findings, and recommendations.

## 6. Key Areas of Analysis
- Respondents' participation in different investment avenues.
- Investment preferences and patterns within the dataset.
- Percentage of respondents who answered Yes to relevant investment questions.
- Summary statistics and KPIs that help communicate the findings.
